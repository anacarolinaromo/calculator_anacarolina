# Simple Calculator

This project is a simple calculator created in Python.

The calculator allows the user to select one of four basic mathematical operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division

The user selects an operation and enters two numbers. The program then performs the selected calculation and displays the result.

## Features

- Add two numbers
- Subtract two numbers
- Multiply two numbers
- Divide two numbers
- Validate the selected operation
- Prevent division by zero

## Running the Calculator

This project was created using `uv`.

To run the calculator from the project folder, use:

```bash
uv run python src/project1/calculator.py
```
